Add your fal key

This tool runs on your own fal.ai account. Create a key at fal.ai/dashboard/keys and paste it here. It's stored on this computer only, never inside your render folder.

Model catalog

Extra models come from a JSON file at a URL you host (GitHub raw file, your site, anywhere public). Render Post reads it on launch and merges it over the built-in models, so new models can be added or re-priced without a new build. Models marked recommended show by default; the rest sit behind "show all".

File format 
{
  "image": {
    "my-model": {
      "label": "My Model · Vendor",
      "endpoint": "vendor/my-model/edit",
      "kind": "nano",                  // "nano": image_urls + resolution; "gpt": image_urls + quality + image_size
      "recommended": false,
      "hint": "what it's good at · price",
      "price": 0.10, "mult": {"1K": 1, "2K": 1, "4K": 2}
    }
  },
  "video": {
    "my-video": {
      "label": "My Video · Vendor",
      "i2v": "vendor/my-video/image-to-video",   // must accept prompt, image_url, duration, resolution
      "recommended": false,
      "hint": "what it's good at · price",
      "res": {"480p": "480p", "720p": "720p"},   // omit if the model has no resolution setting
      "min_duration": 5,
      "price": {"480p": 0.05, "720p": 0.08}      // per second, keyed by resolution, or {"audio": x, "silent": y}
    }
  }
}

Seedance and characters don't mix

Seedance video models refuse frames with realistic people in them. If you send this image to Seedance later (a clip, a take, or a reel frame), the job may fail once the character is in it.
